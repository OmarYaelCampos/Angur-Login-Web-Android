Angur Gestión para Android

1. Instala Android Studio y abre la carpeta android de este repositorio:
   Angur-Gestion/android
2. Espera a que termine Gradle Sync. Si Android Studio pregunta por el SDK,
   acepta instalar Android SDK 36 y los componentes que indique.
3. Inicia la API web y MySQL primero. La app Android valida las credenciales
   contra el mismo servicio y la misma base de datos que la versión web.
4. En la barra superior selecciona la configuración app y un emulador.
5. Pulsa Run (el triángulo verde).

La variante debug se conecta desde el emulador al servidor del equipo anfitrión
en http://10.0.2.2:8080/angur-web. Al iniciar sesión correctamente se muestra
un menú de ejemplo cuyos módulos son visuales y no tienen acciones.

Un teléfono físico no puede usar 10.0.2.2. Requiere configurar una URL accesible
desde el teléfono y usar HTTPS para una instalación real.
